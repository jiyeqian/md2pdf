# 日志分析技能

## 何时使用

- 用户要求「分析日志」「找出报错」「统计异常分布」
- 需要定位某时间段内的错误类型与出现次数

## 快速开始

```bash
log-analyzer --from 2026-01-01 --level error app.log
```

## 常用参数

| 参数 | 说明 |
| --- | --- |
| `--from` | 起始时间（含） |
| `--level` | 过滤级别：error / warn / info |
| `--top` | 只输出出现次数最多的 N 类 |

## 输出说明

命令会输出按错误类型聚合的统计表；若同时给出 `--top`，仅保留前 N 行。
