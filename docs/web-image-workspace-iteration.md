# 图片插入与工作区操作迭代

## 范围

以 `046c354` 为基线，实现本地可验收版本。头部标识改为 MAKE MD2PDF GREAT，示例库采用按钮外观；PDF 下载移入预览标题栏，以图标按钮提供。编辑与预览标题栏分别提供全屏按钮，Esc 退出，保留正文及预览状态。章节同步默认开启。

图片通过截图粘贴、文件拖入或“插入图片”选择，在浏览器本地编码为 PNG / JPEG / GIF / WebP Data URL，插入带唯一图引用标识的 Markdown。长 Base64 内容默认折叠，源码仍完整。大图保留原图或由用户选择压缩，不自动降低专业图表质量。

## 容量与使用限制

- 接受 PNG、JPEG、GIF、WebP，拒绝 PDF/SVG 和无法解码的损坏图片。单图最多 10 MiB，超过 2 MiB 时由用户选择保留、压缩或取消；压缩不一定减小体积，失败或无缩小时保留原图并提示。GIF 压缩会变成静态图。
- 服务端请求最多 24 MiB，内嵌图片合计最多 16 MiB；普通正文仍限制 20 万字符、5000 行、300 个标题与 50 个 Mermaid 块。代码内、未闭合、转义、非法 Base64 或非图片 Data URL 不享受图片字符预算。
- Base64 折叠仅影响显示，保存、复制和 PDF 使用完整源码；选区触及或点击占位可以展开。
- 浏览器会话草稿受存储额度约束。保存失败明确提示，当前编辑仍保留，但刷新可能恢复旧草稿，请先复制并保存源码。
- 图片在浏览器本地编码；排版时作为 Markdown 正文的一部分发送至现有服务器，不新增图片托管服务。
- 全屏采用固定视口面板模式，保留 iframe 实例；不是浏览器系统全屏。章节同步默认开启，可以取消。
