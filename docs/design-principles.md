# 排版设计原则

## 泛化与可推广

优先把章节属性、行内文字、图表说明、脚注归属和行布局实现为共用能力；模板决定样式、默认值及适用的规范检查。来自 GB 模板的能力可以推广到其他模板，不以删除规范约束为代价。

新增语法先检查已有通用能力是否能够表达。显示用的副标题使用通用 `subtitle`，不把显示文字限制为某个模板的枚举值；GB 附录继续检查规范性／资料性标注。内容归属与模板样式分别处理。

## 输入与显示一致

作者填写的可见文字、标点、括号、分隔符和顺序应尽量直接显示；控制属性不作为正文显示。避免隐式替换措辞、补括号或将列表转换为另一种表示。正常 Markdown 格式及浏览器排版仍会处理标记、软换行和空白，不承诺源码逐字节呈现。

自动编号、稳定引用、默认内容和标准版式是明确约定的生成行为。未填写表示采用默认值；显式空字符串表示清空。不能完整解析的输入应提示，不悄悄丢失、移动或错配内容。

关键词采用普通段落，由作者填写分隔符；三格落款直接按左、中、右输入，默认与清空有明确区别。模板的规范检查保留作者文字，给出可定位提示；不擅自把自定义文字替换成推荐文字。
