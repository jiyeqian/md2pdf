# Web 工作台体验迭代

## 范围

本轮以 `381e613` 为基线，在本地实现并验收，不部署、不 push、不打 tag。

- 类型确定后，只显示可配置选项；固定规则由接口同步约束。国家标准保留现有原文元数据、封面和章条编号行为。
- 独立示例展示页提供 Markdown 与对应预览；浏览不覆盖正文，明确选择“使用此示例”后才进入编辑器。结构预留主题展示，暂不扩展主题库。
- 分页预览显示分开的纸张，适配窄屏。
- 预览与 PDF 分别验证目录、脚注、参考文献、图表、公式及返回链接。

## 分工

CodeBuddy `hy4-preview` 负责类型规则、HTTP 约束和示例展示；`space-bunny` 负责分页、引用跳转及 PDF 目标检查。两个 Agent 使用独立仓库快照与日志，Codex 统一整合和验收。补充工作仅从用户指定的 `hy4-preview`、`space-bunny`、`deepseek-v4.1-flash` 中选模型。

## 验收

- [ ] 类型切换与自动识别更新可见配置，旧配置不污染新类型。
- [ ] GB 固定配置不能通过直接 API 请求绕过；原文复现回归通过。
- [ ] 五类示例均在线可渲染，无不可用的图片路径；浏览与采用示例行为分开。
- [ ] 桌面和窄屏的页间分隔可见，脚注与列表跨页正常。
- [ ] 预览内部跳转不加载工作台；重复引用与返回定位正确。
- [ ] PDF 内部链接目标存在且指向有效页，跨页链接通过验证。
- [ ] CLI、HTTP、真实浏览器与 GB 原文回归完成。
