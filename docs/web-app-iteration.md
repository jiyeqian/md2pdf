# Web 工作台体验迭代

## 范围

本轮以 `381e613` 为基线，在本地实现并验收，不部署、不 push、不打 tag。

- 类型确定后，只显示可配置选项；固定规则由接口同步约束。国家标准保留现有原文元数据、封面和章条编号行为。
- 独立示例展示页提供 Markdown 与对应预览；浏览不覆盖正文，明确选择“使用此示例”后才进入编辑器。结构预留主题展示，暂不扩展主题库。
- 分页预览显示分开的纸张，适配窄屏。
- 预览与 PDF 分别验证目录、脚注、参考文献、图表、公式及返回链接。

## 分工

首轮由 CodeBuddy `hy4-preview` 和 `space-bunny` 在独立快照中并行工作，均达到 15 分钟时限，保留中间产物。随后将任务拆成后端策略、预览模块、工作台与示例页面三个明确边界的小任务，使用 `deepseek-v4.1-flash` 并行完成。Codex 负责整合、修复草稿恢复与导出配置问题、独立验收；仅使用用户指定模型。
