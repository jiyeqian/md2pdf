# 分层访问与产品统计

## 原则与实施范围

无需统计同意且有适当法律依据的服务运营汇总自动累计；需要同意的浏览器统计，先征得用户选择再发送。不能以“不使用 Cookie”“不保存 IP”“仅计数”为由自动认定免同意。新增指标先登记目的、字段、来源、依据、保存期限和撤回方式，再决定放在哪一层。

| 层级 | 当前实现 | 边界 |
| --- | --- | --- |
| 自动运营汇总 | 公网 Node 服务端累计日期、固定路由类别、HTTP 状态类别、耗时区间和次数 | 只存在部署者自己的服务器，无访客标识，无请求明细，不自动回传维护者 |
| 访问与活跃统计 | 用户同意后发送访问事件、站点内随机浏览器标识、来源和设备类别 | 可估算活跃浏览器；不代表人数，不跨站或跨设备关联 |
| 产品统计 | 用户另行同意后发送模板、预览、导出和离线状态 | 不携带浏览器标识，不构建个人操作轨迹 |

官方服务端为 `https://md2pdf.app.workbuddy.host/`；官方静态入口为 `https://md2pdf.qianjiye.de/` 和 `https://jiyeqian.github.io/md2pdf/`。本地、局域网和其他 HTTP/HTTPS 自建网站均可在用户同意后上报；CLI 和 file:// 不采集，离线不积压或补传。第三方部署者可关闭或替换接收器。无法阻止修改过的客户端伪造数据，CORS 和公开配置都不是应用身份认证。

## 自动运营汇总

公网模式（配置 `MD2PDF_PUBLIC_HOST`）默认自动累计；本地／局域网模式默认关闭。仅保存 UTC 日期、`page/render/pdf/resolve/other` 路由类别、`2xx/3xx/4xx/5xx` 状态类别、五档耗时区间和计数。任意路径归入 `other`，不保存查询参数、请求体、IP、User-Agent、Referer、文件名、标题或浏览器标识。记录的是请求完成次数，不是 PV、独立用户或成功保存的 PDF；缓存、机器人和重试都会影响口径。

默认快照为部署服务器的 `~/.md2pdf/operational-metrics.json`，每 30 秒或正常关闭时刷新，保留最近 90 个 UTC 自然日。异常退出可能丢失最近 30 秒；不可写时继续内存计数并提示一次，文档处理不受影响。单进程独占文件，多个实例应各自指定文件，不能共写。容器重建可能清空临时文件系统，生产部署应把快照路径放到持久卷；本次未更改 WorkBuddy 的卷配置。它不是中央 Cloudflare 数据库的一部分，无公共查询 API。

```bash
# 在实际部署的服务器上查看，不能用开发电脑的同名文件代替。
cat ~/.md2pdf/operational-metrics.json
# 关闭需重启服务器；更改文件位置也需重启。
MD2PDF_OPERATIONAL_METRICS=0 ./bin/md2pdf webapp
MD2PDF_METRICS_FILE=/absolute/persistent/metrics.json ./bin/md2pdf webapp
```

静态 Pages 没有本应用的 Node 请求处理器，因此不生成此文件。托管平台原生指标、日志权限及安全处理应独立核对，本次没有假定能读取 GitHub Pages 完整流量，也没有通过浏览器自动发 beacon 冒充免同意服务日志。自建站和 localhost 的自动计数不会发送给维护者。

## 同意后上报

访问与产品两项默认关闭，允许全部、拒绝全部和保存选择同等可用，不遮挡编辑器。隐私规则为 policy 2，旧规则的同意不能授权新标识用途，需重新选择。选择在当前 origin 的 localStorage 保存 180 天，其他标签页同步撤回；DNT/GPC 优先禁止上报。部署者开关、配置失败和存储失败均不得默认开启。

访问统计仅在同意后用加密随机数生成 UUIDv4，保存在当前网站来源，不从指纹或 IP 推导。HTTP 本地／自建站同样可用；跨域、跨端口是不同存储空间，可能把同一人重复计算。产品统计不携带这个标识。标识属于假名化数据，不宣称完全匿名；180 天选择到期时清除标识并重新询问。

| 事件 | 允许字段 | 用途 |
| --- | --- | --- |
| `page_view` | 随机浏览器标识、来源类别、限定推广渠道、设备／浏览器／系统／语言类别 | 活跃趋势、渠道与适配 |
| `template_selected` | 内置模板、主题 | 模板使用趋势 |
| `preview_finished` | 成功与否、耗时和文档长度区间、模板 | 排版稳定性和性能 |
| `export_started` | 服务端 PDF／浏览器打印 | 发起导出趋势 |
| `export_failed` | 导出方式、固定错误码 | 排错优先级 |
| `offline_ready` | 资源是否就绪 | 离线能力状态 |

所有事件带版本、服务端／静态方式和粗略部署类别 `official-server/official-static/local/self-hosted`。不发送真实部署域名、内网地址、端口、完整网址／来源、正文、文件名、图片、DOI、异常堆栈或联系人信息。接收器仅为访问事件补充两位国家码，产品事件不补充地理信息。每文档页访问最多一次，预览最多每 30 秒一次，所有事件最多每页每分钟 30 条；这些限制会造成漏计。保存源站类别不能证明网站归属。

页面只保存首次入口的推广类别，限定 `utm_source=github/wechat/zhihu/xiaohongshu`，其余归为 `other`，其他 UTM 不上报。预览耗时包含处理、加载与分页等待，不是引擎基准；浏览器打印无法证明文件已保存。

撤回访问统计后停止上报、尽力取消未完成请求、清除本地标识，并在线尝试向 `/forget` 删除该标识关联的访问记录。离线或删除失败不重试、不补传，余留数据按期限删除；已清空浏览器存储也无法再凭旧标识删除。无标识的产品记录不能按个人定位。恢复备份不会自动重放删除请求，恢复后的服务需先执行清理并核对删除影响。

## 配置与接收服务

公开 `web/analytics-config.json` 仅含开关和 HTTPS `/events` 地址，无密钥。Node 与静态构建共用 `src/analytics-config.mjs`：

```bash
MD2PDF_ANALYTICS_ENABLED=0 ./bin/md2pdf webapp --port 3180
MD2PDF_ANALYTICS_ENABLED=0 node scripts/build-static.mjs
```

这只关闭可选浏览器上报；公网自动汇总另由 `MD2PDF_OPERATIONAL_METRICS` 控制。`MD2PDF_ANALYTICS_ENDPOINT` 可更换接收器，需同时提供兼容的 `/forget`。重启服务或重建静态产物后生效，已有缓存窗口按原流程切换版本。CSP 仅开放配置的接收来源。

接收服务为 `https://md2pdf-analytics.jiye-qian.workers.dev`，独立 D1 为 `md2pdf-analytics`，创建时指定欧盟辖区；Worker 网络处理不保证只在欧盟。逐次事件约 90 天加每日清理间隔；D1 恢复历史可能额外保留已删除数据 7 天（免费）或 30 天（付费），参见 [Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/)。不主动建立长期事件备份。真实部署状态与迁移步骤见 [接收器运维](analytics-worker.md)。

## 报告与指标口径

管理端使用认证 Wrangler，没有公共数据接口：

```bash
cd /Users/jiyeqian/.codex/worktrees/analytics/md2pdf
node integrations/analytics-worker/report.mjs --days 7
```

支持 1、7、30、90 天。事件数与活跃浏览器数分开；后者仅包含同意访问统计且发送成功的随机标识，不包括旧版无标识事件。期间去重不能由每天人数相加得出，同一人换浏览器、域名或清存储会重复计算。维度分组少于 5 条不显示；未同意者不可据样本外推成准确总人数。服务端汇总与浏览器事件不得相加为用户量。

远端上一轮留有 `0.0.0-smoketest` 合成验收事件，不含用户内容，真实分析需排除。查询事件时间列是 `minute`，不是 `received_at`。

## 数据处理依据与后续改进

| 数据处理 | 当前设计依据／上线条件 | 后续核对 |
| --- | --- | --- |
| 部署者本机无标识运营计数 | 用于服务可靠性与容量管理，选择最小化汇总，合理利益候选依据；不是普遍免同意认证 | 运营者记录目的、必要性和利益权衡，核对当地规则与告知 |
| 浏览器访问／产品上报 | 明确、分别、可撤回的用户同意 | 运营主体、隐私联系人、服务商协议和跨境依据 |
| 随机标识与活跃报告 | 仅访问同意后建立，限制当前站点、用途与期限 | 删除审计、误计与机器人、保留窗口内的首次观测不等于新用户 |
| 托管平台访问／安全日志 | 按平台实际设置和独立合法依据处理 | 不把平台原生访客估算默认视为合规认证 |

自动汇总的设计评估：目的是发现服务失败和容量瓶颈；只累计实际处理请求的必要结果，选择计数而非逐请求日志；不识别用户、不关联行为，90 天后清理且不向维护者转发，降低对访客的影响。运营者仍需结合实际用户地区和部署方式确认此评估，不能将它扩展为浏览器免同意遥测的依据。

依据说明：[EDPB 法律依据](https://www.edpb.europa.eu/topics/key-gdpr-concepts/legal-basis_en)、[CNIL 受众测量豁免条件](https://www.cnil.fr/fr/cookies-et-autres-traceurs/regles/cookies-solutions-pour-les-outils-de-mesure-daudience)。法国特定豁免不能直接当作所有地区的规则；暂不增加免同意 UV、跨站标识或本地自动遥测。邮箱留资和推广订阅须独立目的与同意，不复用分析同意。

后续根据真实流量评估：低频批量发送、按事件采样、持久汇总与看板、合法的托管平台流量接入、删除恢复流程、短期标识和更短保留期。没有通过地域猜测自动降低保护。免费额度、读写量和恶意请求必须监控；每天 10,000 条写入上限不能限制所有请求费用。

## 资源与费用边界

本次统计客户端、引导、共用校验和样式合计 17,692 字节（约 17.3 KiB）原始数据，逐文件 gzip 估算合计 7,144 字节（约 7.0 KiB）；不含完整隐私页、HTTP 请求头和 TLS 开销，不代表线上真实压缩传输量。请求正文最多 2 KiB，通常更小；JSON 跨域预检也消耗请求额度。没有常驻轮询或离线事件队列。没有做浏览器 CPU／内存的量化基准。

服务端运营计数为有限维度的内存 Map，最多保留 90 个自然日，30 秒一次快照；不每请求刷盘，不向 Cloudflare 发额外请求。Cloudflare 按事件写表、索引及预算计数，删除和报表同样消耗 D1 额度；首次观测报告会扫描保留的访问历史。不能按一条事件等于一次计费行写入估价。应观察 Workers 请求、D1 读写、容量、拒绝率和清理结果后决定采样或汇总。

## 验收与发布

```bash
cd /Users/jiyeqian/.codex/worktrees/analytics/md2pdf
./bin/md2pdf webapp --port 3180
./bin/md2pdf webapp --static --port 3181
npm run test:analytics
npm run test:analytics-browser
npm run check:consistency
```

本地验收入口同意后也会发送到真实接收器；测试脚本用本机 CDP 拦截统计请求，不向线上写数据。人工操作可先拒绝，检查底栏、编辑和导出，再决定是否同意。验收未同意无事件／无标识、分别同意、随机标识重载稳定、撤回删除、跨标签停止、离线不补传和移动布局；公网自动计数不依赖选择，localhost 没有自动回传。

隐私弹窗使用应用统一样式，首层只解释用途、两项选择和保留期限，完整字段与规则见“完整隐私说明”。更换接收服务时弹窗改称部署者配置的统计服务。底栏左侧为隐私入口、右侧为版本；中央有更新操作或进度时显示状态，否则显示备份提示，普通离线不支持状态不挤占中央提示。

底栏“服务器不保存数据”指用户文档，不代表不保存上述统计；完整隐私说明必须解释这一点。正式 WorkBuddy、Pages 缓存升级、手机实机与系统打印仍需发布后人工验收。修改均在 `codex/analytics`，不自动合并、推送或打标签。
