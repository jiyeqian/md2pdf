## 结果

2026-10-28，封面拉丁字形候选调整后重新验证。本机两套文字分别经真实 CLI、Node PDF 接口和静态共用打印 HTML 输出，共六份 PDF。每份 **36/36 项通过**（23 个原图尺寸箭头 +13 项对齐检查），最大绝对误差 **0.175 mm**。工程阈值为 ±0.2 mm，非 GB/T 1.1 规定的容差。专用字仍为本机候选字体，本记录不证明专用字资源已获确认。

## 复核入口

工作树：`/Users/jiyeqian/.codex/worktrees/f96a/md2pdf`，分支 `codex/template`。

- `npm run test:gb-cover`：重建六份 PDF，以 600 dpi 独立测量全部约束，输出 `/private/tmp/md2pdf-gb-cover-e5/`。
- 图中占位文字封面：`/private/tmp/md2pdf-gb-cover-e5/diagram-node-1.pdf`。
- 实际国家标准范例封面：`/private/tmp/md2pdf-gb-cover-e5/example-node-1.pdf`。
- 原始完整文档同时保存在该目录的 `*-full.pdf`。

PDF 和 PNG 可直接打开，不需服务。要在 WebApp 查看，请从此工作树启动或重启 `./bin/md2pdf webapp --port 8771`，打开 `http://127.0.0.1:8771/` 后从国家标准模板创建，核对封面及导出。不要用其他工作树的旧服务替代。

复核顺序：先看图例封面的标志、横幅、编号、名称和日期/机构相对位置，再看真实范例的长英文及两行机构，最后对照上表。字体或浏览器变更后重新运行脚本；静态系统打印对话框、实体打印机和专用字资源确认不在此自动验收范围。
