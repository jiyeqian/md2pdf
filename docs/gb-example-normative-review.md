# GB 全面范例规范性复核

## 本次处理

以 GB/T 1.1—2020 的 8.3、8.14、9.5.4.1.2、9.9 和 10.2.2 为依据，修改仅作用于 GB。

- 前言的主要技术变化采用第一层字母列项；增加历次版本发布情况，用第一层破折号列项。沿用范例既有的假设标准和被代替文件编号，不表示真实发布历史。
- 删除“技术要求”章与“一般要求”条之间的重复概述；保留术语章的必要引导段。
- 保留 GB/T 12643—2013、GB/T 20000.1—2014 的日期。不注日期意味着接受未来版本及修改单，不宜仅为简化文字而删除；具体术语来源仍保留年份和条号。
- 索引以关键词代替长句：“时钟偏差”“异常切换”等分别指向相关条文；删除指向资料性附录 B 的位置。保留规范性附录 A，继续以稳定标识生成最新编号。中英分区、自动分组和强制字母示例保持。

## 列项实测

`tests/gb-body-acceptance.mjs` 在 CLI、服务端和静态实际分页文档中，分别测量安全状态与异常恢复条中的两个数字列项和两个间隔号列项。坐标按纸张宽度消除预览缩放，并以正文一个 em 为一个汉字的工程测量单位。

第二层标记距版心左边 4 em，正文及回行距左边 6 em（第七字起排），容差 0.02 em。现有 CSS 满足此项，不修改列项样式。测试同时检查实际 PDF 中的字母、数字编号，防止只有 DOM 定位正确而内容缺失。

## 行内字距

原件路径、SHA-256、物理页、段落逐行文字、字符起点间距分布及公式括号坐标记录在 [测量数据](gb-inline-spacing-measurements.json)。以 PDF 文本矩阵的基线聚类，避免不同字体的字框上边缘差异将同一行拆开；只统计相邻的汉字对，不把标点间隔算成汉字间距。

- GB/T 47032—2026、GB/T 48316—2026：物理第 7 页规范性引用文件引导段，前两行汉字起点间距约 10.479–10.771 pt，中位数 10.480 pt；第三行为“本文件。”。第二行在“适用于”后换行。
- GB/T 21922—2026 没有规范性引用文件，不能作为同一引导段的样本。改取物理第 7 页范围段，汉字起点间距约 10.479–10.480 pt，中位数 10.480 pt。

这些值是字形起点间距，不是可直接填入 CSS 的 `letter-spacing`。同一段各行、各位置存在调整，且字形宽度、标点及两端对齐共同影响换行。本次不增加全局字距，不用某一句的换行位置反推全文参数。后续如继续校准，应固定实际字体、字号、版心与标点处理，再对同文逐行比较。

## 公式编号

GB/T 1.1 规定圆括号，未规定必须使用哪个 Unicode 字符。GB/T 47032—2026 物理第 25 页 B.1–B.4 的编号括号抽取为 ASCII，但每个括号的字宽为 9.704 pt，与该字体字号相同，呈全角字宽。

GB 自动公式编号改为全角 `（1）`，作为与参考样本风格一致的实现选择，不将其描述为规范强制的字符编码。使用 MathJax 原有标签格式钩子，计数、稳定标签和引用继续由 MathJax 负责；显式星号标签保留作者输入。其他模板不设置此钩子。验证三入口括号、公式引导点、右侧空间及现有公式释义。
