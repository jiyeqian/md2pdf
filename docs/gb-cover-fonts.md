# GB/T 封面字体核对与本机候选映射

## 结论与适用范围

2026-10-28，针对当前 GB/T 封面与样本的字体差异进行专项修正，尚未实施通用版面校准系统或固定矢量字样资源库。

当前输出的无衬线英文与多个数字样本的粗衬线英文存在明显差异。现将封面 ASCII 字母及连字符映射至本机方正小标宋 GBK 的拉丁字形；在本次所测候选中，它比原方正黑体 GBK 和 Times New Roman Bold 更接近样本轮廓。中文、数字、其他标点、正文以及规定字号保持原有映射。

**这是有轮廓比对依据的视觉近似，不是原字库的精确复刻，也不等于已经证明专用字及拉丁字库符合性。** 样本 E-HZ 的完整原字库尚未取得；仍须保留此差异，不把本轮尺寸通过解释为字体完全一致。

## 规范与样本分别核对

规范依据为研究资料目录下的附录 F，印刷页 58、表 F.1 第 09、10 行，分别规定英文译名和国际一致性程度标识使用“四号黑体”。保留 14 pt，不将规范改写为 Times New Roman、小标宋或样本中的字号数值。

已检查 `~/Workspace/md2pdf-research/gb/Covers` 中七份 GB/T 封面的第一页结构，并目视对照 GB/T 1.1—2020 与 GB/T 48316—2026：

| 样本 | 可用证据与限制 |
| --- | --- |
| GB/T 1.1—2020 | 整页扫描加 OCR 层；图像可见粗体衬线英文。OCR 的 Times New Roman 等字体名不能证明原印刷字体 |
| GB/T 1001.1—2021、13000—2025、42452—2023、48316—2026 | 原生文字；英文主要映射嵌入 E-HZ，数字和部分标点使用其他嵌入字体 |
| GB/T 24067—2024 | 整页扫描，无可直接对应的文字字体，不作为原生字形提取依据 |
| GB/T 7714—2015 | 原生文字，可辅助比较字形；早于 2020 版规范，不用其版式反推新版要求 |

在 GB/T 48316—2026 中，E-HZ 用于拉丁字母和连字符；E-FZ 用于数字、斜杠和破折号，E-BZ 用于句点及空格。GB/T 13000—2025 也显示这类分工，不能把整句英文、数字、标点全部切成同一种粗衬线字体，也不能把少量样本的字符分工作为规范明文。

完整样本文件哈希、实际文字与字体对应、候选字体哈希及八字形测量见 [字体核对数据](gb-cover-font-audit.json)。研究原件不随软件分发。

## 字形轮廓比对方法与结果

从 GB/T 48316—2026 第一页 `/F0` 的 E-HZ 内嵌字体读取字形，仅作本机分析。该子集缺少 cmap/name，7515 个字形槽中仅 34 个非空，PDF ToUnicode 映射 33 项，缺失部分英文字母，不能当作完整字体复用。

使用 CoreText 从候选字体文件直接创建字体，避免按字体家族查询时静默替换。选取 `A H T a e n o s`，核对轮廓路径，并将各字形的可见字框独立归一化为 256×256 灰度图，计算像素交并比。

| 候选 | 八字形交并比范围 |
| --- | ---: |
| 当前本机方正黑体 GBK | 0.243～0.664 |
| 当前本机方正小标宋 GBK | 0.870～0.944 |
| 用户提供的方正小标宋简体 | 0.871～0.951 |
| 本机 Times New Roman Bold | 0.816～0.936 |

此指标只比较归一化形状，不证明字体身份、原始字宽、步进、字距或许可；它不是“字体匹配正确率”。路径点数亦存在差异，不能声称轮廓相同。E-HZ 提取子集的默认步进为 1000，原 PDF 依赖逐字定位，不能用该步进作为真实排字宽度。

选择已安装的小标宋 GBK，复用现有必需字体，不新增字体安装或分发；提供的另一版本虽在本轮部分字形上略接近，仍非完全一致，不据此替换整个字体环境。

## 共用实现与限制

| 对象 | 当前映射 |
| --- | --- |
| 封面 `A–Z`、`a–z`、U+002D | CSS 别名 `GB Cover Latin` → 本机 `FZXBSK--GBK1-0` |
| 封面中文、数字及其余字符 | 原 `GB Hei` 映射；横幅与机构字样原 `GB Cover` 不变 |
| 正文及其他模板 | 保留原字体映射 |

`unicode-range` 仅限定为 ASCII 字母与连字符；轮廓量化抽查了八个字母，不能据此证明其余字形完全匹配，也不保证扩展拉丁、希腊字母或其他字符与出版样本一致。英文译名仍为 14 pt，中文名称仍为 26 pt，不通过压缩文字或降低字号凑宽度。

封面 Latin face 在测量与分页前显式加载，缺失时拒绝导出，不静默回退为无衬线字形。字体只通过 `local()` 读取，未复制字体二进制或样本子集至项目。CLI、服务端与静态共用渲染规则；GB/T 是本次验收范围，不据此宣称 GB/Z 已验收。

HTML 元数据 `md2pdf-gb-cover-latin` 明确标为轮廓比较后的近似。原专用字候选标记保留。
