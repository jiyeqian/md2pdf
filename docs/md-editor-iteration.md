# Markdown 编辑能力迭代

## 范围与边界

本轮以 `0cce7ca` 为基线，同时完成编辑基础与专业辅助，在开发分支本地验收、分阶段提交，不部署、不 push、不打 tag。是否合入 main 另行确认。

- 编辑基础：成熟源码编辑组件、语法高亮、行号、查找替换、撤销重做、缩进、括号配对、列表续接、折叠。
- 常用操作：格式工具栏、快捷键、表格等语法片段、可调整面板和编辑专注模式。
- 专业辅助：标题大纲、引用补全、脚注/BibTeX/公式/图表片段、缺失与重复标识提示、GB 与技能结构片段。
- 双向位置关联按章节提供近似定位；不承诺逐行或逐像素同步。
- 不自动改写正文、frontmatter、原文编号、公式或 BibTeX，不把结构提示当作标准合规审查。
- 保留草稿恢复、示例交接、类型约束、预览沙箱、公共部署 Host/Origin 边界以及既有 CLI/PDF 行为。

## 委派

三个独立 CodeBuddy CLI 并行，分文件所有权；禁止子 Agent 的 Git 和部署操作，由 Codex 整合、关键审查和验收。

| 任务 | 模型 | 文件所有权 |
|---|---|---|
| A 编辑基础 | deepseek-v4.1-flash | editor-core.js/css、editor-vendor.js、许可证和本地打包 |
| B 专业辅助 | space-bunny | editor-pro.js/css、editor-analysis.mjs、分析测试 |
| C 布局定位 | deepseek-v4.1-flash | editor-workspace.js/css、editor-position.mjs、位置测试 |

提示词与原始日志暂存 `/tmp/md2pdf-editor-tasks/`。每个任务最多 70 轮、900 秒；超时保留产物，缩小范围重试。原始日志不提交仓库。

## 构建与限制

CodeMirror 资源随应用本地提供，无运行时 CDN 或新增 npm 运行时依赖。重建用 `node scripts/build-editor.mjs`，需要下载构建依赖；直接依赖固定版本，传递依赖未锁定，不保证逐字节复现。许可证见 `web/editor-vendor.LICENSE.txt`。

章节同步默认关闭，只定位可匹配的标题。引用提示遵循现有渲染器支持的标识规则；不替代标准合规审查。真实中文输入法的候选选择与组合输入仍需人工验收。撤销历史只在当前编辑会话保留，刷新恢复正文不恢复历史。
