# GB 国标 md 模板与写法约定

> 用途：把一份国家标准（GB/GB\T）排成接近现行版式的 A4 PDF。
> 识别：frontmatter 含 `标准号` 或 `standard` 时自动判为 `gb`（也可 `--type gb` 显式指定）。

---

## 1. frontmatter 字段

写在文件开头 `---` 之间。**键名允许中文**。

| 字段 | 作用 | 说明 |
| --- | --- | --- |
| `标准号` | 封面右上 + 正文页眉 | 如 `GB/T 39999—2026`（也认 `standard`） |
| `title` | 封面中文名称 | 缺省时取正文首个 H1 |
| `英文名称` | 封面英文名称 | 也认 `title_en` |
| `ICS` | 封面左上 | 如 `25.040.30` |
| `CCS` | 封面左上（ICS 下方） | 如 `J 28` |
| `发布日期` | 封面下方 | 也认 `date` |
| `实施日期` | 封面下方 | — |
| `代替标准` | 封面（如「代替 GB/T …」） | 可选 |
| `发布机构` | 封面机构块第一行 | 缺省为「国家市场监督管理总局」 |
| `发布机构2` | 封面机构块第二行 | 缺省为「国家标准化管理委员会」；两行之间自动排「发布」 |
| `文件类别` | 封面标题行 | 缺省为「中华人民共和国国家标准」，按字均分撑满两边距 |

`前言` 里的「提出单位 / 归口单位 / 起草单位 / 起草人」按国标惯例写在**正文**里（不属封面字段）。

示例：

```yaml
---
标准号: GB/T 39999—2026
title: 仿生机械手抓取控制系统技术要求
英文名称: Technical requirements for grasping control system of bionic manipulators
ICS: 25.040.30
CCS: J 28
发布日期: 2026-01-01
实施日期: 2026-07-01
代替标准: GB/T 39999—2019
---
```

## 2. 章节结构

用**标准标题层级**书写即可，**不要自己写编号**（编号由工具生成）：

| 层级 | 写法 | 结果 |
| --- | --- | --- |
| `##` | `## 前言` / `## 引言` / `## 范围` | 前言/引言**不编号**；范围从 `1` 起 |
| `##` | `## 规范性引用文件` / `## 术语和定义` / `## 技术要求` | `2` / `3` / `4` … |
| `###` | `### 抓取成功率` | `3.1`、`4.1` … |
| `####` | `#### 单指响应延迟` | `4.2.2` … |
| `##` | `## 附录 A（规范性）试验方法` | 附录标题**不自动编号**（字母写在标题里），其下条为 `A.1`、`A.2` |
| `##` | `## 参考文献` | **不编号** |

要点：
- **前言 / 引言 / 目次 / 参考文献**：不编号、也不占号（`范围` 仍从 1 开始）。
- **附录**：标签写在标题里（`附录 A（规范性）…`），工具只负责其下条编号为 `A.1`；资料性附录写 `附录 B（资料性）…`。
- 表格用标准 Markdown 表格，题注写在**表格上一行**：`表：说明 {#tab:x}`（可选标签，供 `\ref{tab:x}` 引用）。
- 参考文献推荐用 **BibTeX 脚注**：正文 `[^id]` 引用，文末 `[^id]: @book{…}`，工具按 GB/T 7714-2025 渲染并自动汇总为「参考文献」章节。

## 3. 版式（主题 `gb`）

- **字体**：优先 `方正书宋_GBK` / `方正黑体_GBK`，缺失时回退 `Songti SC` / `Heiti SC`（本机通常回退，观感接近）。
- **封面**：独立一页、无页眉页码；坐标按正式发布版实测还原——ICS/CCS 左上（≈10mm）、
  **GB 标志右上**（内置矢量 assets/gb-logo.svg，由 tools/trace-gb-logo.mjs 从官方封面 600dpi 渲染描迹生成，
  源位图 tools/gb-logo.src.png 留档可复现）、「中华人民共和国国家标准」撑满两边距（≈41mm）、
  标准号右对齐（≈60mm，代替标准紧随其下，**下方一根全宽横线**）、
  中文名称居中（≈115mm，**方正小标宋**）、英文名称居中（≈134mm，**Times 衬线**；标准编号为黑体）、
  日期行「发布靠左 / 实施靠右」（≈250mm，**行下一根全宽横线**）、
  机构块（≈263–276mm）：名称两行 17pt/行距 18pt 左对齐，**「发 布」14pt 两字间空格、
  不占行位、垂直中心恰在两行名称分界线上、水平距名称右缘 ≈1em**（GB/T 48051-2026、
  GB 21520-2023、GB/T 14394-2008 三份官方标准实测一致）。
- **页边距**：上 25 / 右 19 / 下 20 / 左 25 mm（装订边左宽，实测自正式发布版；profile 默认值）。
- **页眉**：标准号——奇数页（右页）靠右、偶数页（左页）靠左；由 Paged.js 的 `@page :left / :right` margin box 绘制。
- **页码**：前置部分（目次/前言/引言）大写罗马数字，正文从「1 范围」起阿拉伯数字重新计数；封面无页码。
- **分页**：GB 类型由内置 Paged.js 接管（Chrome 原生 `@page` 做不到奇偶页眉与 `target-counter`）；其他类型不走 Paged.js，行为不变。
- **表格**：三线表；章/条标题用黑体；正文不用圆点/序号标记。
- **目次**：标题为「目次」（默认开启），条目「标题 + 点线 + 真实页码」，前置部分条目显示罗马页码。

## 4. 用法

```bash
md2pdf 标准.md                 # 自动识别为 gb
md2pdf 标准.md --type gb       # 显式指定
md2pdf 标准.md --no-toc        # 不要目次（gb 默认开）
md2pdf 标准.md --theme minimal # 换回普通主题（不走 GB 版式）
```

完整示例见 `examples/gb-sample.md`（产物 `examples/gb-sample.pdf`）。

## 5. 已知边界（待未来完善）

**字体缺失（当前最大观感差距）**

- 官方封面嵌入字体为 **方正小标宋（FZXBSK）/ 方正黑体（FZHTK）**，正文为方正书宋；多数机器没有这些字体，实际按回退链落到 华文中宋/宋体、黑体、Songti SC —— 观感接近，非逐像素一致。
- 英文名称用 Times 衬线，缺 Times 时落 Tinos/系统 serif。
- 可选的彻底方案（未做）：随 npm 包内嵌开源替代字体的子集（如思源宋体/思源黑体仅封面所需字形），或在文档探测到缺失时提示。

**封面版式的已知偏差（相对正式发布版，均 ≤3mm 量级）**

- 日期行位置比官方约高 3mm（为保机构块不拆页的取舍）。
- 机构块三行的行距比官方略松（官方三行墨迹跨度 ≈34pt，我们 ≈50pt）。
- GB 标志为从官方 PDF 提取的 1-bit 位图（600dpi），未矢量化；官方封面右上无其他元素。

**Paged.js 相关（上游行为，已在本仓库规避/覆盖）**

- 强制分页会触发 Paged.js 给前页元素打 `data-align-last-split-element` 属性，把段落末行也两端对齐拉伸 —— 已用覆盖规则还原，属上游 bug，未来可考虑升级/上报 pagedjs 后移除覆盖。
- `@page gb-cover` 的下边距疑似未按声明值生效（内容区底边按 20mm 基准计算），已显式改为 12mm 绕过；升级 pagedjs 后建议复核。
- 横线 1pt 在不同渲染分辨率下粗细有 ±0.5pt 波动（栅格取整，可接受）。

**样例产物策略**

- `examples/*.pdf` 是提交到仓库的产物；**只在对应输入（md/主题/CSS/渲染逻辑）变动时才重新生成**，无关样例不重渲，减少无意义 diff。
- `ci/build-demo-assets.sh` 目前是全量重建，未来可按输入文件 mtime/哈希做增量跳过。
- PDF 字节永不逐位一致（见 CODEBUDDY.md「Known issues」：/CreationDate 时间戳），比对以内容为准。

### 其他

- GB 文末不输出落款条（`--colophon` 对 gb 不生效）。
- Paged.js 分页约多花几百毫秒，仅 gb 类型；封面/目次/前言/引言/附录/参考文献各自起新页，数字章之间不强制新页。
