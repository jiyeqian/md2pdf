# GB 国标 md 模板与写法约定

> 用途：把一份国家标准（GB/GB\T）排成接近现行版式的 A4 PDF。
> 识别：frontmatter 含 `标准号` 或 `standard` 时自动判为 `gb`（也可 `--type gb` 显式指定）。

---

## 1. frontmatter 字段

写在文件开头 `---` 之间。**键名允许中文**。

| 字段 | 作用 | 说明 |
| --- | --- | --- |
| `标准号` | 封面右上 + 正文页眉 | 如 `GB/T 39999—2026`（也认 `standard`） |
| `title` | 封面中文名称 | 缺省时取正文首个 H1 |
| `英文名称` | 封面英文名称 | 也认 `title_en` |
| `ICS` | 封面左上 | 如 `25.040.30` |
| `CCS` | 封面左上（ICS 下方） | 如 `J 28` |
| `发布日期` | 封面下方 | 也认 `date` |
| `实施日期` | 封面下方 | — |
| `代替标准` | 封面（如「代替 GB/T …」） | 可选 |
| `发布机构` | 封面下方 | 缺省为「国家市场监督管理总局 国家标准化管理委员会」 |

`前言` 里的「提出单位 / 归口单位 / 起草单位 / 起草人」按国标惯例写在**正文**里（不属封面字段）。

示例：

```yaml
---
标准号: GB/T 39999—2026
title: 仿生机械手抓取控制系统技术要求
英文名称: Technical requirements for grasping control system of bionic manipulators
ICS: 25.040.30
CCS: J 28
发布日期: 2026-01-01
实施日期: 2026-07-01
代替标准: GB/T 39999—2019
---
```

## 2. 章节结构

用**标准标题层级**书写即可，**不要自己写编号**（编号由工具生成）：

| 层级 | 写法 | 结果 |
| --- | --- | --- |
| `##` | `## 前言` / `## 引言` / `## 范围` | 前言/引言**不编号**；范围从 `1` 起 |
| `##` | `## 规范性引用文件` / `## 术语和定义` / `## 技术要求` | `2` / `3` / `4` … |
| `###` | `### 抓取成功率` | `3.1`、`4.1` … |
| `####` | `#### 单指响应延迟` | `4.2.2` … |
| `##` | `## 附录 A（规范性）试验方法` | 附录标题**不自动编号**（字母写在标题里），其下条为 `A.1`、`A.2` |
| `##` | `## 参考文献` | **不编号** |

要点：
- **前言 / 引言 / 目次 / 参考文献**：不编号、也不占号（`范围` 仍从 1 开始）。
- **附录**：标签写在标题里（`附录 A（规范性）…`），工具只负责其下条编号为 `A.1`；资料性附录写 `附录 B（资料性）…`。
- 表格用标准 Markdown 表格，题注写在**表格上一行**：`表：说明 {#tab:x}`（可选标签，供 `\ref{tab:x}` 引用）。
- 参考文献推荐用 **BibTeX 脚注**：正文 `[^id]` 引用，文末 `[^id]: @book{…}`，工具按 GB/T 7714-2025 渲染并自动汇总为「参考文献」章节。

## 3. 版式（主题 `gb`）

- **字体**：优先 `方正书宋_GBK` / `方正黑体_GBK`，缺失时回退 `Songti SC` / `Heiti SC`（本机通常回退，观感接近）。
- **封面**：独立一页、无页眉页码；ICS/CCS 左上、标准号右上、中英文名称居中、发布/实施日期与发布机构在下方。
- **页边距**：上 25 / 右 19 / 下 20 / 左 25 mm（装订边左宽，实测自正式发布版；profile 默认值）。
- **页眉**：标准号——奇数页（右页）靠右、偶数页（左页）靠左；由 Paged.js 的 `@page :left / :right` margin box 绘制。
- **页码**：前置部分（目次/前言/引言）大写罗马数字，正文从「1 范围」起阿拉伯数字重新计数；封面无页码。
- **分页**：GB 类型由内置 Paged.js 接管（Chrome 原生 `@page` 做不到奇偶页眉与 `target-counter`）；其他类型不走 Paged.js，行为不变。
- **表格**：三线表；章/条标题用黑体；正文不用圆点/序号标记。
- **目次**：标题为「目次」（默认开启），条目「标题 + 点线 + 真实页码」，前置部分条目显示罗马页码。

## 4. 用法

```bash
md2pdf 标准.md                 # 自动识别为 gb
md2pdf 标准.md --type gb       # 显式指定
md2pdf 标准.md --no-toc        # 不要目次（gb 默认开）
md2pdf 标准.md --theme minimal # 换回普通主题（不走 GB 版式）
```

完整示例见 `examples/gb-sample.md`（产物 `examples/gb-sample.pdf`）。

## 5. 已知边界

- 方正字体多数机器没有，实际回退系统字体 —— 观感接近，非逐像素一致。
- GB 文末不输出落款条（`--colophon` 对 gb 不生效）。
- Paged.js 分页约多花几百毫秒，仅 gb 类型；封面/目次/前言/引言/附录/参考文献各自起新页，数字章之间不强制新页。
