# WebApp 使用说明

## 一个入口，两种打开方式

WebApp 可以在浏览器中打开，也可以添加到主屏幕，以独立窗口使用。两种方式共用界面、草稿保存逻辑、安装资源和更新机制；主屏模式不是独立产品或版本。

每个部署只使用一个固定入口：服务端部署使用根地址 `/`，静态部署使用其发布目录。没有单独的 `/app/` 入口。服务端和静态部署的能力区别见 [静态部署 WebApp](static-webapp.md)。

- 服务端部署：首次联网准备后支持离线启动、编辑、草稿恢复和 Markdown 下载；排版预览、PDF 导出和 DOI 查询需要联网及服务可用。
- 静态部署：资源准备后支持离线编辑、排版和 PDF 导出；DOI 查询仍需要联网。
- 添加到主屏幕后适配安全区、键盘视口与后台恢复；支持系统文件分享时提供分享操作，否则使用下载。

## 导航、编辑与侧栏

顶部编辑器、模板库按钮始终保留各自图标和目标，当前页面按钮显示底色。左侧品牌文字为“MAKE MD2PDF GREAT”，字体、字号保持不变；标语作为背景始终保留，窄屏导航按钮可覆盖其上，不增加顶栏行数。顶栏高 60px，按钮保持 42×42px。浏览器标签在编辑器显示 `md2pdf`，模板库显示 `模板库 · md2pdf`。

“基础格式”菜单在有序列表之后提供任务列表，插入 `- [ ] `，可对选中多行逐项转换；左右缩进移至独立一行。

编辑侧栏与预览侧栏停靠在各自面板正文右侧，占用独立宽度，正文重新排布；侧栏宽度不超过面板一半，保留拖动调整。点击编辑或阅读区域、切换全屏、交换 M/P 均保留展开状态；再次点击入口、点击叉号或按 Esc 关闭。

侧栏顶部左侧为视图切换图标，右侧为关闭按钮。编辑侧栏提供文档大纲、专业助手；预览侧栏提供文档大纲、页面缩略图。切换内容时保持展开和宽度，再次打开恢复上次视图。专业助手中的引用、章节与作者单位检查和文档类型默认折叠。两侧大纲均支持折叠子章节。

缩略图仅在该视图打开时加载，复用当前浏览结果，不重新排版；整个缩略图栏使用一个隔离容器，仅加载可见页和相邻页，离开该视图时释放内容。点击缩略图跳转到对应页面。流式浏览显示一张连续长页缩略图，不改变浏览方式；分页缩略图跳转时以上一页底边为浏览区顶部，避免露出上一页。界面控件保留常规边框和悬停反馈，不显示额外聚焦高亮外框。

## 文档分页策略

在 frontmatter 设置 `chapter-start: continuous | page | odd-page`，分别连续排版、章从新页开始、章从奇数页开始；章指正文 `##`；首章默认与标题同页。“基础格式”二级菜单的任务列表之后提供“插入分页符”：保留选中文字，在光标或选区末尾插入独占一行的标记，光标停在标记后的新行，支持单步撤销。正文也可独占一行输入 `<!-- pagebreak -->` 强制分页，代码示例中的同样文字不生效。输入字段冒号后可选择候选值。跨页表格默认重复表头。两项均作用于分页预览和 PDF 导出，流式阅读保持连续；详细规则见[配置说明](configuration.md#章分页与跨页表格)。

## 页面边界与留白

顶栏和通栏底栏均使用白底与细分隔线，左右边距一致。底栏最小高度 36px，窄屏按原左、中、右顺序变为上、中、下三行并居中，自然增高；内容较少时落在浏览器底边，手机上下排列时位于第二个面板之后，随页面滚动，不覆盖编辑或阅读区域。工作区高度计入底栏实际高度，底栏状态换行及键盘视口变化时重新计算。

工作区使用可用宽度，外围桌面左右 16px、上下 10px，窄屏左右 12px、上下 8px；面板之间保留同步按钮所需空间。按钮点击区域、正文与 PDF 页内留白不变。多行选区浮动菜单按无序列表、有序列表、任务列表、引用块排列，任务列表插入未完成标记，重复选择可移除标记。

## 预览工具栏

国家标准（含自动识别为 gb）仅显示“打开 Markdown”和“模板”两个工具栏入口；切换到其他模板后恢复对应可用控件。

预览工具栏首个“打开 Markdown”按钮与编辑器入口共用文件选择、草稿切换和覆盖确认流程；预览全屏时也可直接打开其他文档。主题按钮后的页面方向按钮切换横向／纵向排版，未操作时继承文档配置；国家标准固定纵向，不显示该按钮。其后的浏览方式按钮在分页与连续流式浏览之间切换，默认分页，仅改变当前预览，不写入 frontmatter 或 PDF 导出配置；本标签页编辑文档后保留浏览方式，刷新后恢复分页。两种部署共用这些操作。流式主题样式通过 CSS `@scope` 与分页副本隔离，需要支持该语法的现代浏览器。

浏览方式回归检查：`npm run test:preview-mode-browser`；检查已启动静态版：`node tests/preview-mode-browser-checks.mjs http://127.0.0.1:8773/`。覆盖连续原文、公式图表、大纲与目录跳转、编辑后保持模式、打印仍分页及窄屏底栏顺序。

## 服务端启动与访问

在本工作树启动：

```bash
cd /Users/jiyeqian/.codex/worktrees/6654/md2pdf
./bin/md2pdf webapp --port 8765
```

也可以直接使用已安装的 `md2pdf webapp --port 8765`。电脑访问 <http://127.0.0.1:8765/>。如继续使用已配置的 Caddy 代理，手机访问 <https://web.mbp16.qianjiye.de:8443/>，浏览器和主屏图标均使用这个根地址。

可信 HTTPS 或电脑 localhost 才能准备离线缓存。局域网 HTTP 可以在线使用，但不能准备离线启动资源。

局域网直接访问时，用电脑当前私有 IPv4 地址启动：

```bash
MD2PDF_LAN_HOST=192.168.1.9 PORT=3116 node src/server.mjs
```

手机访问 `http://192.168.1.9:3116/`。未设置时默认仅监听本机；不能与 `MD2PDF_PUBLIC_HOST` 同时启用。电脑需保持服务运行并允许端口入站访问。

## 安装、离线与更新

1. 联网打开固定入口，等待底栏“准备离线资源…”消失。浏览器和主屏模式自动使用各自部署的缓存机制。
2. 如需独立窗口，在浏览器分享菜单选择“添加到主屏幕”。首次从图标打开时保持联网，再确认资源已就绪。
3. 断网后可以通过同一地址或主屏图标重新打开。编辑后确认“草稿已保存到此浏览器”，重要文档及时下载 Markdown 备份。
4. 底栏出现“保存并更新”时，点击该文字。保存失败保留当前页面；未更新的窗口继续使用其原版本资源。

缓存只保存界面资源和公开配置、模板；用户正文保存在 IndexedDB，渲染请求和导出结果不进入服务端 WebApp 的离线缓存。桌面浏览器也使用相同的资源缓存与更新机制，服务端排版及 PDF 导出流程不变。

草稿按浏览器及来源隔离，不自动跨设备同步。协议、端口、域名变化会形成不同存储；系统也可能隔离浏览器与主屏窗口的存储。清理网站数据或系统回收存储可能删除缓存和草稿，需要联网重新准备并从下载备份恢复。

本项目尚未发布，不提供旧 `/app/` 测试入口迁移。旧测试图标可删除后从根地址重新添加；旧测试缓存可以在浏览器网站数据设置中清理。清理前先下载需要保留的草稿。

## 验收

- 桌面浏览器：打开、创建、草稿切换、缩放、全屏、模板库、预览和下载。
- 主屏模式：检查独立窗口、安全区、键盘弹出、快捷菜单、后台返回、文件下载及系统分享。
- 缓存就绪后停止服务或断网，刷新根地址，检查草稿恢复与 Markdown 下载；服务端部署恢复连接后检查预览。
- 更新资源后检查提示、保存后更新，以及其他旧窗口继续编辑。

静态部署的构建、PDF 大纲和 GitHub Pages 使用方法见 [静态部署 WebApp](static-webapp.md)。手机系统分享与打印仍需实体设备验收。

## 版本核对

CLI 的 `md2pdf --version`、服务端及静态 WebApp 均从 `package.json` 读取产品版本。页面底部说明栏右侧显示 `v版本号`，悬停查看部署方式和提交号；版本号不可点击；状态和操作居中，窄屏移到下一行左侧，版本仍靠右。发布 tag 必须为对应的 `v版本号`，发布前核对一致性。开发改动通过提交号区分，不代表该 tag 已包含全部开发修改。

服务端更新代码后需要重启；静态部署重新构建。缓存页面显示其实际加载版本的信息，出现更新提示时保存草稿后更新。Git 仓库不存在时仍可显示产品版本，提交号可以省略。

## 底栏状态

左侧为隐私与统计入口，中间显示备份提醒或以下资源状态，右侧为版本号。窄屏依此顺序纵向显示三行。“下载备份”仍下载 Markdown；版本号为纯文字，无弹出面板。准备完成后显示备份提醒，不显示自动浮层、页头说明栏或断网横幅。

| 状态 | 文字／操作 |
| --- | --- |
| 准备中 | 准备离线资源… |
| 新版可用 | 保存并更新 |
| 资源失败／不完整 | 重试离线准备 |
| 更新前保存失败 | 保存失败请重试 |
| 更新检查失败 | 检查更新 |
| 环境不支持 | 不支持离线启动 |

保存失败、资源失败优先于更新提示；重试成功后恢复相应状态。更新前必须保存成功，失败保留当前页面。更新和离线准备可稍后处理。草稿保存、预览与 DOI 提示保留原功能位置。
