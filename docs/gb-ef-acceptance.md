# 国家标准 E、F 本机排版验收

## 本次范围与结论

2026-10-27，从 main `a28c3c6`（v1.16.1）同步后的 `f96a / codex/template` 工作树实现。本轮针对国家标准，行业、地方标准暂缓。

已按 [逐项对照](gb-ef-requirements.md) 实现并验收本机字体环境下的适用版式：A4、镜像边距、页眉页码、前置罗马数字／正文重置、正文右页开始、正文首页名称和重要提示、附录三行标题、图表目录、跨页表头与续表题、术语／注／示例／来源／单位陈述／图表脚注、条文页底脚注、参考文献、索引、末页终结线及封底。

**不能将本记录解释为无条件的全部符合声明。** 封面 GB 标志复用仓库现有素材；国家标准横幅、发布机构专用字目前为本机小标宋候选，尚未取得发布部门字样的逐字核验依据。专用字状态在 HTML 元数据 `md2pdf-gb-cover-glyphs` 中明确为候选。附录 E、F 未指定普通字体可自动替代这些专用字，本轮不将候选字形计为已经证明合规。

## 字体与环境

- macOS 本机 Google Chrome／Chromium 排版，Poppler 检查输出。
- `GB Song` → 本机 `方正书宋_GBK`，PostScript 名 `FZSSK--GBK1-0`。
- `GB Hei` → 本机 `方正黑体_GBK`，PostScript 名 `FZHTK--GBK1-0`。
- `GB Cover` → 本机 `方正小标宋_GBK`，PostScript 名 `FZXBSK--GBK1-0`，仅专用字候选。
- 字体通过 `local()` 使用，没有复制到仓库、包或静态目录；三个字体缺失时停止预览／导出，避免静默回退。
- PDF 的 `pdffonts` 结果确认以上字体嵌入子集，字体不作为可下载的网页资源分发。

## 验收边界

- 本轮未验收手机、缺少这些字体的服务器、Safari、公开 Pages 部署及旧缓存升级，不据本机结果声称这些环境通过。
- 静态路径验证了打印专用文档；实际系统“保存为 PDF”对话框和物理打印机的缩放／双面装订仍需人工核对。打印应采用实际尺寸，不用适合纸张缩放。
- 测试坐标以浏览器字框为主要证据，PDF 文本框用于复核；字体墨迹与字框存在差异，不把浏览器公差当成规范许可的尺寸公差。
- raster 图片内部的字体无法由 CSS 自动校正；术语、图表注、单位和索引需作者采用文档约定并提供正确内容。未闭合语义块按普通文字保留，不计为该专业角色已符合规范。
- 复杂合并表格、单行高于整页的表格、超长脚注跨页和极长注块不属于本次综合样例的已验证范围，不能推导为所有输入都可自动合规。
- 封面专用字与发布部门素材核验完成前，本轮只能作为本机可审阅版式成果，不能标注为正式发布部门认可的最终稿。
