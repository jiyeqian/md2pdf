# GB/T 发布机构字距核对

## 范围与结果

2026-10-28，先处理“国家市场监督管理总局”“国家标准化管理委员会”两行字距，再返回原字形复用问题。本次仅增加机构名称的字距，保留字号、行高、字形比例及字体映射，不提取或合并字库。

| 对象 | 相邻字首步进 |
| --- | ---: |
| 四份较新原生 GB/T 封面，两行各九个间隔 | 6.777919 mm |
| 修改前实际 PDF，两行 | 5.995455 mm |
| 修改后三入口实际 PDF，两行 | 6.775454 mm |

采用 `.cover-org-name { letter-spacing: .78mm; }`，与参考字首步进相差约 0.0025 mm。`.78mm` 是当前字体下的实现参数，**不是图 E.5 明示的规范尺寸，也不是可见笔画间空白的宽度**。

## 样本和测量端点

选用 GB/T 1001.1—2021、13000—2025、42452—2023、48316—2026 第一页，两行机构名各十字。直接测量原生 PDF 的相邻字形排字原点，四份结果一致。来源、原件哈希、逐字坐标与工程阈值见[独立样本记录](../tests/fixtures/gb-issuer-spacing.json)。

GB/T 1.1—2020 的封面是扫描加 OCR，OCR 字框不作为原始精确字距依据；GB/T 7714—2015 的机构排布不同，不据此设定新版两行机构的字距。

自动回归检查最终分页 DOM 的逐字原点；另用 pdfplumber 独立测量三入口实际 PDF，结果见[PDF 测量记录](gb-issuer-spacing-measurements.json)。字首原点、字体度量框、可见墨迹边缘分别对待，不把三者混为同一测量端点。

## 相关约束与剩余差异

两例三入口的原 36 项 PDF 墨迹检查全部通过：机构文字下缘距纸底 20 mm，机构右缘至“发”5 mm、“发”至“布”3 mm，以及整体中心 x=110 mm 等保持有效。新增每行九个字首间隔回归检查，工程阈值 ±0.03 mm；该阈值也不是标准规定的容差。

现有字形与样本的字面宽度仍有差别，因此字首步进匹配不等于每一对笔画边缘间空隙完全相同。本次不通过非等比缩放字形去消除该差别。后续采用原字形时，应保持独立记录的目标步进，按新字形度量重新计算实现字距，不机械沿用 `.78mm`。
