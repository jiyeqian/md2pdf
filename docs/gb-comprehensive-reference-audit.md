# GB 综合范例参考核对

## 范围与证据

以 GB/T 1.1—2020 为规则依据，三份 2026 年标准只用于观察实例。页码均写为「PDF 物理页 / 印刷页」；物理页从 PDF 第一页起计。原文件路径及 SHA-256 见同目录 JSON。核对通过抽取文字、整页渲染和部分 PDF 字符坐标完成；样本的视觉效果不能自动转化为规范义务。

## 规范明确要求

- 书眉：10.1.3 要求从目次开始，单数页右侧、双数页左侧编排文件编号（规则 40 / 33）；附录 F 表 F.1 第 47 项规定五号黑体（66 / 59）。
- 术语：10.3.5 要求英文对应词位于术语之后，两者间空一个汉字；除原文需要大写外用小写（41 / 34）。表 F.1 第 23 项规定术语及英文对应词五号黑体（65 / 58）；未在此表中单独规定普通英文正文的具体西文字族。
- 前言和引言：10.3.3 要求另起一面，符合图 E.9；图 E.9 展示两字疏排，引言同式（41 / 34，61 / 54）。表 F.1 第 16—19 项规定标题三号黑体、内容五号宋体（65 / 58）。图示未给字间距数值。
- 参考文献：10.3.6 要求另起一面、标题居中，符合图 E.10；所列文件空两字起排，回行顶格，序号与文件编号、编号与文件名之间空一汉字，末尾无标点（41–42 / 34–35，62 / 55）。表 F.1 第 29—30 项分别规定标题五号黑体、内容五号宋体（66 / 59）。图示未给标题字间距数值。
- 列项：7.5.1、7.5.3 规定列项符号和字母编号的使用及结束标点；最后一项以句号结束（18–19 / 11–12）。10.2.2 规定第一层破折号或字母编号空两汉字起排，内容及回行从第五汉字位置开始；第二层空四汉字、内容及回行从第七汉字位置开始（40 / 33）。字母编号用于需要识别或顺序的第一层，不应强行把所有列项改成字母编号。
- 图表：9.7.2、9.8.2 要求图表编号；图题和表题宜有且各自保持一致（33–34 / 26–27）。9.8.1.3 禁止分表、表中套表和带表头子表（34 / 27）。9.8.3 规定续页重复表编号，后接可选表题及“（续）”或“（第#页/共*页）”，重复表头及单位陈述（35 / 28）。10.4.2 要求表外框、表头框、表注和表脚注所在框为粗实线，表题居中置上、图题居中置下；未在此处给出线宽数值（42 / 35）。
- 公式：9.9.2–9.9.3 要求需要引用或提示时编号，变量用字母符号，未事先列出的符号在式后说明（36–37 / 29–30）。10.4.3 要求居中排公式、编号右对齐并用“……”连接；“式中：”与各符号释义空两字起排，释义用破折号连接且各行破折号对齐（42 / 35）。此处未规定引导点三点分组、组间距离或指定数学字体。

## 样本观察与待确认

- 47032 11 / 5：表 1 是多级表头与纵向合并单元格，表注占整行，外框和表头边界视觉上较粗。18–19 / 12–13 的表 A.2 为跨页大型填写式复杂表，续页标题含“（续）”，内部为不同子区段和合并单元格；不宜未经逐项判断就断言它违反重复表头规则。48316 13–14 / 7–8 的表 1 续页重现四列表头，表格单元格中还有 a)、b) 等列项。
- 21922 8 / 2 的术语及英文对应词均呈粗体，之间有空隙；21922 5 / III 的“前言”疏排，正文含较长字母列项。48316 13 / 7 的列项回行对齐正文，而非编号。
- 47032 25 / 19 的公式变量呈斜体，公式后为连续点线。PDF 字符分析显示部分点线是连续 U+2026 字形，起点约 10.5 pt 等距；视觉不能证明三点组之间另有空隙，不能把它当作规范强制。式中释义用长横线；标准编号中的连接号与列项和释义的破折号承担不同语义，不能一概替换。
- 47032 11 / 5 书眉字符抽取中 GB、T 使用嵌入字体 E-HZ，数字、斜线及连接号使用 E-FZ；21922、48316 对应页也观察到此组合。与附录 F 将文件编号列为五号黑体之间存在字形实现差异；仅凭嵌入字体名不能认定样本不合规或确定可替代字体。公式、英文正文具体字体族与标题的精确字距仍未确认。

## 最小实现目标

范例应覆盖正确的术语英文对应词、长字母列项及回行、语义不同的破折号、公式编号及释义、多级合并表头和含表注的复杂表、可核验的续表及重复表头。GB 样式按规范规则优先；样本仅作为版面参考，未知的精确数值或字体不冒充规范。跨页续表、字体和实际 PDF 输出须在 CLI 与 WebApp 分别人工核验；该文档本身不证明实现或视觉验收通过。
