# GB 全面范例与逐项验收

## 原则与唯一来源

GB/T 1.1—2020 为最高依据，目录内三份 2026 年正式标准用于实例核对，不将样本习惯冒充规范义务。参考文件、页码、哈希和未确认项见[参考核对](gb-comprehensive-reference-audit.md)及[证据清单](gb-comprehensive-reference-ledger.json)。目前未确认必须升级处理的条款冲突，也没有需要新增参考文件才能实现的项目；47032 跨页分区表头不能未经判定就视为违规。

唯一维护的全面范例是 `web/examples/gb.md`，同时用于模板库、从模板创建和三入口实际 PDF 验收。CLI展示副本 `examples/gb.md` 由 `npm run generate:gb-example` 逐字节同步，`npm run check:gb-example` 与一致性检查拒绝漂移；`templates/gb.md` 维持空白骨架，不复制演示正文。GB演示构建先同步源，可用 `bash scripts/build-demo-assets.sh --gb-only` 只更新GB PDF与封面图，卡片预览用 `node scripts/generate-template-previews.mjs --type gb` 更新。已删除旧 `tests/fixtures/gb-body-calibration.md`；固定的历史回归夹具保留用于防退化，不再作为第二份同步维护的范例。范例标明为假设标准，数据不能用于实际产品判定。

`<!-- gb-check: ... -->` 为 GB 校准注释，围栏外不印出，围栏内按代码保留；CLI 与 WebApp 一致。

## 字体、字距和线条的边界

- 页眉和术语英文参考原件呈粗衬线，采用本机 `TimesNewRomanPS-BoldMT` 作为 **ASCII 字母**候选，中文和数字仍走黑体。它不是规范点名的西文字库，也不声称是 E-HZ 原字形。
- 运行环境需安装方正书宋、黑体、小标宋及 Times New Roman 普通／粗体；导出前检查字体加载，不随仓库重新分发字库。正文保持方正书宋；GBK 缺少的数学负号和间隔号显式回退本机 Times，避免无意落入系统宋体。公式为 MathJax SVG，变量斜体、运算符正体，不声称与原件数学字形完全相同。
- 21922 物理第5页的“前言”字首 x 为 270.55/317.71 pt；物理第29页“参考文献”字首约为 265.22/286.17/307.13/328.09 pt。结合字形与空格，前引言采用两字间隙、参考文献采用一字间隙；CSS 的 2em/1em 与居中补偿属于工程选取，图 E.9/E.10 未给出强制字距数值。
- 标准编号中的一字线、正文列项与释义中的两字破折号、数学负号分别处理，不做全文字符替换。公式引导点为连续省略号；不额外制造未经证明的三点组间隙，公式与引导点保留约 2 mm 工程间隔。
- 表格外框、表头和表注框采用 0.764pt，内部采用 0.327pt，均为黑色，取自47032样本测量。分页后叠加SVG规则线，避免浏览器将不同CSS边框量化为同一宽度；实测PDF有效线宽与上述值一致。规范规定粗实线关系，但没有指定这两个pt数值。普通单元格留白收窄，长表分页前锁定列宽。
- 行高 1.62 是当前样本导向设置，不是 GB/T 1.1 给出的固定 CSS 数值。实体打印和其他字体环境仍需核对。

## 复杂表格写法

普通表格继续使用 GFM。合并表格采用 GB 专用的受控块，单元格支持安全行内 Markdown，禁止原样透传 HTML：

```markdown
表：检测记录

:::gb-table
widths: 30 70 65
head:
| {rowspan=2} 对象 | {colspan=2} 记录 |
| 项目 | 结果 |
body:
| {rowspan=2} 控制器 | 稳态 | 合格 |
| 恢复 | 合格 |
:::

:::gb-note scope=table position=top align=right
单位为毫米
:::
```

`widths` 是列宽权重，可省略为等宽；每行必须填满网格，跨行单元格不能越过表头／表体分界。支持最多 12 列、500 行，非法跨度、缺格或属性返回明确错误。跨行连通组保持同页，组过高时要求作者拆分，不静默裁切；不支持嵌套表、跨页超大合并组或任意 HTML 属性。复杂表单元格中的图片和相对资源链接返回明确的400错误，请将图放在独立图中；单元格链接只接受 HTTP/HTTPS、mailto 和锚点，代码中的字面写法不误判。普通 Markdown 表格的既有图片行为不受此限制。

单位陈述使用 `:::gb-note scope=table position=top align=right`，写在对应表格之后；渲染时置于表题文字与表格之间，并随续表重复。图同样在对象后定义，使用 `scope=figure position=top`。完整的九个指令及参数规则见[模板说明](gb-template.md)。

## 本轮补充校准

GB/T 1.1 无规定的项目按所供正式样本执行，工程取值不冒充规范数值。目次深度为2，正文目录、图目录、表目录各块内所有条目采用相同的12.2267pt正文行高及上下各3.0567pt（四分之一行）留白，目标基线间距18.34pt；组间留一行。层级仅通过缩进体现。实际数值为本轮紧凑排版的工程选择，不是规范指定的固定行高。正文列表、注与示例去掉额外块间距，章标题的规范间隔保留。两幅图展示清单行距，注与示例展示本地连续编号。

索引使用真实省略号，位置分别链接到章条、术语、图表及附录；未解析的位置保持文字而非编造链接。正文文献上标继续显示，参考文献增加长题名以展示自然回行。第3.2.1条采用GB/T 1.1所引原定义，演示单层中括号来源，不将来源错误归给自拟机器人术语。

`:::` 补全与解析器共用 `src/gb-blocks.mjs`，仅有效国家标准模板启用；参数、内容和成对关闭行自动补齐，已有非空块保留正文，代码围栏内不触发。服务端与静态构建均包含该模块。

正文范例另含5.6.1.1、5.6.1.2四级章节，以及3.1分类下的3.1.1～3.1.3和3.2分类下的3.2.1术语。长注展示自然回行与内容左对齐，条文脚注从前言到正文再到附录连续为1）～3）。引导段只标记章标题与下级条标题／术语条目之间的普通段落：缩进两字、回行顶格、无附加段落外边距；标题本身的章／条／术语间距规则保持独立。

参考文献条目取消额外段后间距，使条目内、条目间使用相同行距；索引条目行高收紧为1.45并保留字母分组间距，链接去掉下划线但仍可跳转。目次改用真正省略号字符，并限制伸缩占位，防止挤压标题。

示例默认写法仍为 `:::gb-example`，等价于 `:::gb-example layout=block`；标签单独一行，正文首行空两字、续行顶格。单个文字段可用 `:::gb-example layout=inline` 让标签与正文同行，续行顶格。指定inline但含多段、列表、代码等复杂内容时返回明确错误，不因窗口、字数或分页自动改变布局。未手写标签的多个示例按所在章条或术语条目局部连续编号；显式旧标签保留。补全菜单提供“标签独立”和“标签同行”。

新增文献GB/T 1526—1989的长题名已用所供GB/T 1.1参考文献和[官方详情](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=D19A1DF7C8A8058E26EC8DFE9EBD001B)核对；术语来源GB/T 20000.1—2014见[官方详情](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=BA6DE806E0BDF1BE7A35EE0B236F8E15)。核对日期2026-10-29。

## 2026中英索引（默认范例风格）

以21922、47135两份2026标准的共同出版实践为索引版式参考，GB/T 1.1仍为最高依据。新版GB范例及补全优先使用中英分区：汉语拼音双栏、英文对应词单栏，分区标题通栏；英文可接在中文结束后的同一页。两份样本的普通行距均约15.72pt、字母分组典型过渡约47.16pt（含字母标题），详见测量台账。栏间采用3mm工程值。

```markdown
## 索引 {role=index}

:::gb-index-section lang=zh

:::gb-index C
采集信息 | 6.1
:::

:::gb-index Z
抓取成功率 | @grasp
:::

:::

:::gb-index-section lang=en

:::gb-index G
grasping success rate | @grasp
:::

:::
```

`@grasp`指向已有 `:::gb-term id=grasp`。位置编号和跳转随自动术语编号更新；关键词与分组顺序按作者给出的拼音／英文顺序保留，不猜测多音字。英文关键词使用已有GB西文粗体候选，不宣称是样本原字库。

旧 `:::gb-index A` 独立分组继续保持原单栏、原行距；不会根据文字内容自动迁移。新中文分区可显式写 `lang=zh columns=1`。英文分区固定单栏；非法语言、栏数、非索引内容或未闭合分区给出明确错误。补全提供中文分区、英文分区、旧分组三种入口。

新分区按左栏自上而下、再右栏、再下一页阅读，分组可续栏，字母标题与第一条同栏；索引单条不跨页，超出单页高度明确拒绝。长关键词自然回行，编号靠右对齐末行；分页后只调整引导点，不移动关键词或链接，不遮盖文字。索引终结线沿用现有同页规则。

专项验收涵盖12条短中文索引、150条跨页中文索引（每组含长词）及英文条目、14条旧单栏中文索引；检查实际PDF内容完整且每项一次、阅读顺序、标题与首条同栏、引导线不遮挡、重复校准不移位。真实编辑器验证分区补全与嵌套关闭行。记录见 `gb-index-layout-acceptance.json`，运行 `node tests/gb-index-layout-checks.mjs`。Node全面范例仍为19页，本轮未重新生成CLI／静态交付PDF，三入口共用渲染一致性检查通过。未代替Safari、手机或实体打印验收。
