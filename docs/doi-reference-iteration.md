# DOI 参考文献插入

## 行为与边界

编辑工具栏保留脚注按钮，BibTeX 与 DOI 使用各自专用单色图标。DOI 按钮打开查询对话框，输入 DOI 或 doi.org 链接，显式解析后将 BibTeX 写回 Markdown 脚注；正文引用与脚注定义属于同一次编辑事务。

相同 DOI 复用已有脚注；只有 DOI 的定义可在再次解析后补全。代码示例中的脚注不参与去重。解析期间正文改变或对话框取消，不能把迟到结果写入正文。

失败时保留原文，允许重试、仅插入 DOI 或手动填写 BibTeX。仅 DOI 的脚注仍可预览与导出，编辑栏提示尚未补全。手动条目中的 DOI 必须与输入一致。出版标题、年份或支持类型缺失时停止自动生成；其他字段缺失明确提示，不猜填。

首版自动支持期刊论文、会议论文、图书。Crossref 查询返回未找到时回退 DataCite；不支持的类型由用户手动补全。服务进程只缓存成功查询，按条数限制，重启清空。普通预览、导出及 CLI 转换不会查询 DOI。

## 网络与部署

浏览器只调用同源 `POST /api/doi`，请求体仅包含 DOI。服务访问固定的 Crossref / DataCite HTTPS API；不访问用户输入的任意网址，不跟随跳转，限制响应体、查询时长及并发数。已上线服务部署新版本后，需要允许服务器出站访问 `api.crossref.org` 与 `api.datacite.org`。

查询服务依赖公开注册元数据，内容及完整性以提供方记录为准，作者仍应核对著录。接口错误、网络不可用或超时均不改变正文。
