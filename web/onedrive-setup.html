OneDrive 配置说明

返回 md2pdf。此设置由部署者完成，未配置不影响本地编辑和下载。

注册微软应用

在 Microsoft Entra 的“应用注册”中新建应用，支持个人 Microsoft 账户，平台选择“单页应用（SPA）”，添加 Microsoft Graph 委派权限 Files.ReadWrite.AppFolder。使用公开的应用程序（客户端）ID，无需创建客户端密钥。

回调必须与实际访问地址匹配，并在微软应用中注册。例如访问 http://localhost:3000/，回调为 http://localhost:3000/onedrive-callback.html；静态站点 https://example.com/md2pdf/ 的回调为 https://example.com/md2pdf/onedrive-callback.html。其他部署需要 HTTPS。

填写部署配置

源码 Node 部署先在项目目录执行：

cp web/onedrive-config.example.json web/onedrive-config.json

填写配置并重启工作台：

{
  "clientId": "你的公开客户端 ID",
  "redirectUri": "http://localhost:3000/onedrive-callback.html"
}

npm 全局安装的配置位于 $(npm root -g)/@jiyeqian/md2pdf/web/。静态部署在构建后填写产物目录中的 onedrive-config.json；每次重新构建后需重新配置。Docker 可将宿主机配置文件只读挂载至 /usr/share/nginx/html/onedrive-config.json。不要填写密钥或令牌。

localhost 与 127.0.0.1 的浏览器草稿不共享，切换地址前请先下载备份。
