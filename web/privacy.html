隐私与统计

返回 md2pdf · 在应用底部“隐私与统计”中查看、更改或撤回选择。

自愿选择

访问统计和产品统计默认关闭，只有你分别同意后才发送。拒绝不影响编辑、预览和导出。应用遵循浏览器的“不跟踪”（DNT）及全球隐私控制（GPC）信号：开启这些信号时不发送统计。

隐私选择通过 localStorage 保存在当前浏览器和网站来源中，仅包含选择、隐私规则版本和保存时间，不含文档内容。访问统计另保存仅限当前网站的随机浏览器标识，只有同意访问统计后才生成；产品统计不携带此标识。选择有效期为 180 天；过期后重新询问。更换浏览器、清理存储或切换域名需要重新选择。无法保存选择时保持关闭。

自动汇总与可选上报

底部“服务器不保存数据，请及时下载备份”指用户文档；统计计数和经同意的访问、产品事件按本说明另行保存。

公网服务端基于处理实际请求累计日期、固定路由类别、状态类别、耗时区间和次数等基础汇总，保留最近 90 个 UTC 自然日，只保存在部署者自己的服务器，可由部署者关闭，不生成浏览器标识，也不上传文档内容用于统计。托管平台自身的网络、安全日志遵循其政策。点击“拒绝全部”仅关闭下述可选浏览器上报，不关闭这些无需统计同意的服务运营汇总。它们与浏览器上报分开；本地或他人自建部署不会因此自动向维护者上报。

采集范围与用途

  • 访问统计：站点内随机浏览器标识、部署类别、国家／地区（由 Cloudflare 从网络请求推断的两位国家码，不是精确定位）、程序版本、服务端／静态部署方式、来源类别（直接、搜索、社交、其他推荐、推广）、限定的推广渠道类别、设备类别、浏览器类别、操作系统类别及语言类别。
  • 产品统计：内置模板／主题标识、预览成功与否、预览耗时区间、文档长度区间、发起导出的方式、固定错误码，以及离线资源就绪状态。

这些数据用于判断推广渠道、设备适配优先级和功能稳定性。只发送类别和区间，不发送完整网址、查询参数、来源网址、完整 User-Agent 或精确定位。浏览器打印仅能统计发起打印，无法确认 PDF 已保存。

统计不包含 Markdown 正文、文档标题、文件名、图片、参考文献、DOI 查询内容或原始异常堆栈；不保存姓名、邮箱、IP 地址或浏览器指纹。随机浏览器标识用于估算日活、月活、新增和回访浏览器，不能代表准确人数，不跨网站或设备关联。不提供会话录像、键盘记录或跨站跟踪。此功能不收集营销订阅或发送推广邮件。

服务与保留期限

网站由 GitHub Pages 或你使用的服务端提供。自建统计接收器运行于 Cloudflare Workers，经你同意的事件保存在 Cloudflare D1。无论本地、局域网还是其他自建网站，开启此功能都会将有限统计发送给 md2pdf 维护者，而非仅保存在你自己的服务器；部署者也可关闭统计或配置其他接收器。应用不加载 Cloudflare Web Analytics 跟踪脚本。统计明细保留约 90 天，通过每日清理任务删除过期记录，清理间隔可能额外增加约一天。当前未设置长期保留汇总，也不主动创建长期事件备份。Cloudflare D1 自动恢复历史无法关闭：免费套餐可恢复过去 7 天，付费套餐为 30 天，因此删除的记录可能在恢复历史中额外存在相应时间，详见 D1 恢复历史说明。

网络服务商处理 HTTPS 连接时会接触 IP 等请求信息；应用统计数据库不保存这些信息，也不主动记录原始请求日志。服务商自身的网络、安全和运营处理受其政策与账户设置约束，并非“网络层绝不接触个人信息”。参阅 Cloudflare 隐私政策 和 GitHub 隐私声明。服务可能在你所在国家或地区之外处理网络请求。

撤回、离线与反馈

在应用底部打开“隐私与统计”，点击“拒绝全部”或取消相应选项并保存，即停止后续发送，并尽力取消尚未完成的请求。取消访问统计后清除本地随机标识；在线时尽力向接收器发送删除请求，删除该标识关联的访问记录。删除失败或离线时不排队补传，剩余记录按保留期限清理。产品记录不带访客标识，不能按个人定位删除。清理浏览器存储后也无法再凭旧标识提出删除。服务商恢复历史仍按其期限保留；从备份恢复后必须重新执行过期清理。

离线不发送统计，不排队补传离线行为。统计服务不可用不应阻碍文档操作。应用不会因拒绝统计减少功能。

对隐私说明或采集范围有疑问，请通过 项目反馈 联系维护者。反馈为公开内容，请勿提交个人信息或私密文档。
