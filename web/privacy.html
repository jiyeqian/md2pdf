隐私与统计

返回 md2pdf · 在应用底部“隐私与统计”中查看、更改或撤回选择。

自愿选择

访问统计和产品统计默认关闭，只有你分别同意后才发送。拒绝不影响编辑、预览和导出。应用遵循浏览器的“不跟踪”（DNT）及全球隐私控制（GPC）信号：开启这些信号时不发送统计。

隐私选择通过 localStorage 保存在当前浏览器和网站来源中，仅包含选择、隐私规则版本和保存时间，不含访客标识。选择有效期为 180 天；过期后重新询问。更换浏览器、清理存储或切换域名需要重新选择。无法保存选择时保持关闭。

采集范围与用途

  • 访问统计：国家／地区（由 Cloudflare 从网络请求推断的两位国家码，不是精确定位）、程序版本、服务端／静态部署方式、来源类别（直接、搜索、社交、其他推荐、推广）、限定的推广渠道类别、设备类别、浏览器类别、操作系统类别及语言类别。
  • 产品统计：内置模板／主题标识、预览成功与否、预览耗时区间、文档长度区间、发起导出的方式、固定错误码，以及离线资源就绪状态。

这些数据用于判断推广渠道、设备适配优先级和功能稳定性。只发送类别和区间，不发送完整网址、查询参数、来源网址、完整 User-Agent 或精确定位。浏览器打印仅能统计发起打印，无法确认 PDF 已保存。

统计不包含 Markdown 正文、文档标题、文件名、图片、参考文献、DOI 查询内容或原始异常堆栈；不保存姓名、邮箱、IP 地址、持久访客标识或浏览器指纹。不提供会话录像、键盘记录或跨站跟踪。此功能不收集营销订阅或发送推广邮件。

服务与保留期限

网站由 GitHub Pages 或你使用的服务端提供。自建统计接收器运行于 Cloudflare Workers，允许的不含访客标识的事件保存在 Cloudflare D1。应用不加载 Cloudflare Web Analytics 跟踪脚本。统计明细保留约 90 天，通过每日清理任务删除过期记录，清理间隔可能额外增加约一天。当前未设置长期保留汇总，也不主动创建长期事件备份。Cloudflare D1 自动恢复历史无法关闭：免费套餐可恢复过去 7 天，付费套餐为 30 天，因此删除的记录可能在恢复历史中额外存在相应时间，详见 D1 恢复历史说明。

网络服务商处理 HTTPS 连接时会接触 IP 等请求信息；应用统计数据库不保存这些信息，也不主动记录原始请求日志。服务商自身的网络、安全和运营处理受其政策与账户设置约束，并非“网络层绝不接触个人信息”。参阅 Cloudflare 隐私政策 和 GitHub 隐私声明。服务可能在你所在国家或地区之外处理网络请求。

撤回、离线与反馈

在应用底部打开“隐私与统计”，点击“拒绝全部”或取消相应选项并保存，即停止后续发送，并尽力取消尚未完成的请求。已到达服务端的记录无法通过浏览器撤回；由于不保存个人标识，维护者也无法按个人识别和删除某一条记录，记录会按保留期限清理。

离线不发送统计，不排队补传离线行为。统计服务不可用不应阻碍文档操作。应用不会因拒绝统计减少功能。

对隐私说明或采集范围有疑问，请通过 项目反馈 联系维护者。反馈为公开内容，请勿提交个人信息或私密文档。
